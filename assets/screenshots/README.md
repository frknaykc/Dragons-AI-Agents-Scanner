# Terminal screenshot verification

These PNGs were captured from a real macOS Terminal.app window running Dragons from a local checkout. Terminal was set to a neutral title/prompt and Menlo at 15 pt; no CLI output was redrawn or composited. AppleScript sent each command to the same tab, and `screencapture -x -l <Terminal window ID>` captured the complete window, including the typed command and exit summary. The window ID is session-specific. The screenshots were visually reviewed for completeness and private paths; the commands were also rerun in a non-interactive shell to verify exit codes and report contents. No finding text or status was edited in the images.

| Image | Exact command typed in Terminal | Fixture | Exit | Verification |
| --- | --- | --- | ---: | --- |
| [dragons-help.png](dragons-help.png) | `uv run --offline dragonscan --help` | None | 0 | Usage/help visible; command matches output. |
| [dragons-clean-scan.png](dragons-clean-scan.png) | `uv run --offline dragonscan scan benchmarks/corpus/benign-credential-guide/AGENTS.md` | Bundled inert benign fixture | 0 | `COMPLETE`, `PASS`, zero findings visible. |
| [dragons-security-finding.png](dragons-security-finding.png) | `uv run --offline dragonscan scan /Users/Shared/Dragons-CLI-Demo/SKILL.md` | Inert copy of bundled `benchmarks/corpus/pi-override/SKILL.md` | 0 | `DRAGON-PI-001`, `HIGH`, one finding, `PASS` visible; no severity gate requested. |
| [dragons-severity-policy.png](dragons-severity-policy.png) | `uv run --offline dragonscan scan /Users/Shared/Dragons-CLI-Demo/SKILL.md --fail-on high` | Same inert copy | 1 | `DRAGON-PI-001`, `HIGH`, `POLICY_VIOLATION` visible. |

The shared demo fixture contains only the single inert line from the repository fixture; no real agent installation or private configuration was scanned. The generic `/Users/Shared/Dragons-CLI-Demo/` path avoids a personal home path in terminal output. The copy can be prepared on macOS with `mkdir -p /Users/Shared/Dragons-CLI-Demo && cp benchmarks/corpus/pi-override/SKILL.md /Users/Shared/Dragons-CLI-Demo/SKILL.md` from the repository root; the screenshots are from the real commands above, not from that setup command. The `--offline` flag belongs to `uv` and requires its interpreter and dependencies to be available locally. Exit codes were checked separately because the terminal UI does not print the process exit value by default.

JSON and SARIF report-generation commands and an error diagnostic were also executed (not pictured): `uv run --offline dragonscan scan /Users/Shared/Dragons-CLI-Demo/SKILL.md --format json --output /Users/Shared/Dragons-CLI-Demo/scan.json` (0), the same command with `--format sarif --output /Users/Shared/Dragons-CLI-Demo/scan.sarif` (0), and `uv run --offline dragonscan scan benchmarks/corpus/missing/SKILL.md` (3). Both local reports parsed as JSON, with the expected format-specific top-level keys. Neither report is included in the repository.
